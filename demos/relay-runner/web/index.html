Very low FPS? Check your graphics adapter

Chrome can say “WebGPU: Hardware accelerated” while this game uses SwiftShader, a software renderer running on your CPU. Press F3 in the game to see the adapter and frame rate.

On Linux with Chrome, try:

  1. Open chrome://flags/#enable-vulkan, set Vulkan to Enabled, then relaunch Chrome.
  2. Reload this page. F3 should show your GPU vendor, such as NVIDIA or AMD, instead of SwiftShader.

If Vulkan is unavailable or the problem remains, check chrome://gpu under Dawn Info / WebGPU Adapter Info and follow Chrome’s WebGPU troubleshooting guide.
