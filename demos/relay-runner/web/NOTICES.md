# Relay Run demo assets

This is a non-commercial browser demo and evaluation of Asset Forge's game-asset
pipeline. The Rust source's MIT/Apache licenses do not grant new rights over
sample assets or upstream generator components.

The committed runtime assets are unchanged bytes selected from the accepted
`relay-runner-v16` package. `asset-receipt.json` records their SHA256 digests and
the source delivery record's digest. Original sidecars accompany generated models,
audio and the reload clip; character assemblies retain their bundle records.
The two library JSON snapshots are runtime metadata from the source libraries,
not a claim that every source-library asset is hosted here. Full references,
generation trials and private review evidence remain outside this web payload.

Character and prop texture baking used nvdiffrast, whose non-commercial notice
continues to apply. These assets are not represented as cleared for commercial
use. Resolve upstream terms or replace affected assets before commercial release.
Pixal3D's MIT code notice is included in `licenses/PIXAL3D-LICENSE`; it does not
remove restrictions attached to other pipeline components. Generator models,
weights and runtimes are not distributed here.

The nine Pixal3D models have reconstructed provenance and make integrity claims,
not reproducibility claims. Their original sidecars remain unchanged; the web
build does not recast them as supported TRELLIS generation records.

Original deterministic effects/music and generated announcer/effect audio retain
their accompanying asset records. Lato's license is at `assets/fonts/LICENSE.txt`.
The Hanabi particle-system notice and source licenses are in `licenses/`.
`licenses/ORIGINAL-SCRAPYARD-NOTICES.md` is an unchanged historical notice from the
native delivery; its private-build paths refer to that source delivery, not to
additional files promised by this browser subset.
