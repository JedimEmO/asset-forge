# Shared Scrapyard asset sources

Relay Run is the current game showcase. Scrapline, its source, production
reports, rejected drafts and review sheets are preserved in the
[archive/scrapline-20260906 tag](https://github.com/JedimEmO/asset-forge/tree/archive/scrapline-20260906).
The archive points to commit `92f8866bf7e93c62f3c0efefbd5f1100e6b5e61b`.

This folder retains the original reference paths named by Forge records,
image prompts, audio source manifests, VFX atlases and rifle attachment used
by the external consumer fixture. The original asset notices were moved here
unchanged. Accepted assets and their records remain in `assets/` and
`assets-src/`; none were regenerated or edited during archival.

The older production reports and tools referenced by historical release notes
are available under their original paths in the archive. Clone that tag into a
separate directory to run Scrapline or inspect its evidence.
