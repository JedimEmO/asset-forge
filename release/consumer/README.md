# External consumer fixture

Development fixture for Bevy 0.19. Run `python3 verify.py /absolute/path/to/fixture`
then `cargo run --manifest-path /absolute/path/to/fixture/Cargo.toml -- /absolute/path/to/fixture`.
The argument locates assets and review outputs regardless of working directory.
The program checks six named animations and writes runtime evidence and screenshots.
See the delivered `CONTRACT.md` for delivery and runtime ownership.
